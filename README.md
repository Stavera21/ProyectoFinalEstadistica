## 🚀 Instalación

**1. Clonar el repositorio**

```bash
git clone https://github.com/Stavera21/ProyectoFinalEstadistica.git
```

**2. Entrar al directorio**

```bash
cd ProyectoFinalEstadistica
```

**3. Instalar las dependencias**

```bash
pip install numpy pandas scipy matplotlib openpyxl
```

## ▶️ Ejecución

Cada punto puede ejecutarse independientemente desde la carpeta principal:

| Archivo | Ejecución |
|---|---|
| Punto 1 | `python Punto1.py` |
| Punto 2 | `python Punto2.py` |
| Punto 3 | `python Punto3.py` |

> **Nota:** Los archivos Excel utilizados como entrada deben permanecer en las ubicaciones indicadas por los scripts.
